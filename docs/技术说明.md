# 技术说明

## 1. 项目概述

“灵动手势收藏屋”是一个完全运行在浏览器端的实时手势交互应用。项目使用 TensorFlow.js 调用 MediaPipe Hands 模型，从摄像头画面中检测手部关键点，并将识别结果用于字母编码、双手计数、语音播报和动态物品抓取。

项目维护者：李雨（420231159029）。

## 2. 系统结构

```text
摄像头视频
   ↓
MediaDevices.getUserMedia
   ↓
MediaPipe Hands（每只手21个关键点）
   ├── 手指数统计 → 双手加数 → A—Z编码 → 英文播报
   ├── 捏合距离判断 → 抓取/释放 → 物品移动
   └── Canvas渲染 → 骨架与关键点显示
```

主要模块：

| 文件 | 作用 |
| --- | --- |
| `src/main.js` | 页面初始化、模型加载和摄像头开关 |
| `src/js/camera.js` | 摄像头媒体流管理 |
| `src/js/detector.js` | 检测循环、结果平滑和字母播报 |
| `src/js/gesture-recognition.js` | 手指数统计和A—Z编码 |
| `src/js/interaction.js` | 物品抓取、拖放、中文播报和反馈动图 |
| `src/js/renderer.js` | Canvas手部关键点绘制 |
| `src/js/voice.js` | 中文物品播报和英文字母播报 |
| `src/index.css` | 白底黑字单屏响应式界面 |

## 3. 手指数统计

系统对拇指、食指、中指、无名指和小指分别比较“指尖到手腕”与“中间关节到手腕”的距离。指尖距离明显大于关节距离时，判定该手指处于伸直状态。

算法使用相对距离比例，不依赖固定像素长度，因此能适应手掌距离摄像头远近的变化。

## 4. A—Z编码

单手模式：伸出1—5根手指分别识别为A—E。

双手模式：按照镜像画面中的横坐标区分左侧手和右侧手，编码公式为：

```text
编码 = 左侧手指数 × 6 + 右侧手指数
```

编码1—26依次映射为A—Z，同时独立显示：

```text
双手总数 = 左侧手指数 + 右侧手指数
```

示例：左侧手4根、右侧手2根时，编码为 `4×6+2=26`，对应字母Z。

系统保存最近7帧识别结果，并取出现次数最多的编码，以降低关键点短暂抖动造成的字母跳变。

## 5. 抓取交互

抓取逻辑使用拇指尖和食指尖之间的欧氏距离：

- 距离小于40像素：抓取手势。
- 距离大于或等于40像素：张开手势。

抓取时记录光标相对物品左上角的偏移量，移动过程中利用该偏移量更新物品位置，并限制物品不超出收藏区域。

## 6. 动图与语音反馈

收藏台包含彩虹棒棒糖、惊喜礼盒、向日葵花束和爱心抱枕。每个物品关联一个本地GIF反馈素材。抓取成功时：

1. 弹出对应的动态反馈卡片；
2. 使用中文语音播报物品名称；
3. 物品进入高亮抓取状态。

字母识别稳定变化后，Web Speech API 使用英语语音播报当前字母。物品中文播报与字母英文播报互相独立。

## 7. 隐私与运行方式

视频帧、手部关键点和识别结果均在浏览器本地处理，不上传到业务服务器。首次使用时只需要授予当前本地网页摄像头权限。

开发服务器由Vite提供，默认地址为 `http://localhost:5173/`。
