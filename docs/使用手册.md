# 使用手册

## 1. 环境要求

- Node.js 20或更高版本；当前验证版本为22.14.0。
- npm；当前验证版本为11.11.0。
- Chrome或Edge浏览器。
- 可用摄像头和正常网络连接。

## 2. 安装与启动

打开PowerShell并执行：

```powershell
cd D:\hand_gesture_grab
npm install
npm run dev
```

浏览器访问：

```text
http://localhost:5173/
```

## 3. 启动摄像头

1. 点击“启动摄像头”。
2. 浏览器询问权限时选择“允许”。
3. 等待页面状态显示检测到手部。
4. 保持光线充足，并让完整手掌进入摄像头范围。

页面顶部“本地实时识别”前的状态灯表示识别链路状态：红色为未连接（未启动或已关闭摄像头），绿色为正在实时识别。摄像头启动过程中按钮、状态栏与状态灯都会同步给出反馈。

页面刷新后浏览器会关闭旧媒体流，需要重新点击一次“启动摄像头”。

页面顶部有三个功能按钮：

- “字母识别”：显示手指数、编码与A—Z识别结果。
- “收藏品抓取”：在右侧收藏台抓取和布置动态物品。
- “球体抓取”：在左侧实时摄像头画面中托举、拍击或抓取彩色弹力球。

三个模式相互独立。收藏品抓取和球体抓取模式会隐藏并暂停字母识别、字母编码和英文播报。

## 4. 识别字母

- 握拳时识别为0；识别程序会检查拇指是否收在掌内，避免拳头被误判为1。
- 单手1—5根手指对应A—E。
- 双手比拼两位数编码：左右手指数直接拼接，拼接数字1—26对应A—Z（如 2 与 3 拼成 23 → W）。
- 页面会显示两侧手指数、拼成的编码数字，以及与编码对应的字母。
- 当前字母会在A—Z列表中高亮，并使用英语播报。

常用示例：

| 目标字母 | 左侧手 | 右侧手 |
| --- | --- | --- |
| A | 1 | 0 |
| B | 2 | 0 |
| L | 1 | 2 |
| O | 1 | 5 |
| W | 2 | 3 |
| Y | 2 | 5 |

## 5. 抓取收藏品

手势抓取：

1. 张开拇指和食指，将屏幕光标移动到收藏品上方。
2. 捏合拇指和食指完成抓取。
3. 移动手掌拖动收藏品。
4. 再次张开拇指和食指释放收藏品。

鼠标布置：

- 直接用鼠标（或触屏）按住收藏品拖动，松手放下；物品会被限制在收藏台内部。

成功抓取后，页面会弹出对应动图并播报真实物品名称。

## 6. 抓取摄像头画面中的球体

1. 点击页面顶部“球体抓取”。
2. 多颗彩色高光球会从画面顶部依次下落，从底部离场消失后重新从顶部进入并持续循环，不会撞击地面。
   球体模式使用更宽的3:4竖屏摄像区域，优先请求720×960竖屏视频；电脑摄像头仅支持横屏时会裁去左右两侧，保留人物上下方向。把身体和双手放在画面中央即可。
3. 张开手掌并移到球体下方，可接住并托举球体；快速挥动手掌可把球弹性拍开。
4. 捏合拇指和食指抓住球体，移动手掌拖动。
5. 张开拇指和食指释放球体，球体会继续受重力下落。

球体具有侧边碰撞和球间碰撞，抓取、放开或拍击时只产生柔和粒子反馈，不显示收藏品弹窗，也不播报名称。没有启动摄像头时，也可以用鼠标拖动球体检查交互效果。

隔空控制手势：

- 握拳：开启紫色吸引力场，将一定范围内的球体吸向掌心。
- 张掌：从球下方托举；快速移动手掌碰球可完成拍击。
- 食指点按：只伸出食指并移动指尖触碰球体，可进行更轻、更精确的弹击。
- 单手捏合：抓取球体，捏得越紧球体压缩越明显；移动后放开可按手速抛出。
- 双手捏合：两手同时靠近同一个球后，改变双手距离可拉伸或压缩球体。
- 投入目标：把经过手势控制的球送入画面中的目标圈，计分加一并重新生成球体。

快速抛出或拍击球体时，球后方会显示渐隐运动轨迹，帮助观察运动方向和速度。

### 6.2 创新交互

- 张掌力场：静止张掌产生斥力，手指张得越开，作用范围越大；缓慢移动时产生黏性跟随，掌面倾斜会带动球横向滚动。
- 旋转涡流：保持张掌并连续旋转手腕，附近球会绕掌心形成涡流。
- 双手空间：双手靠近或展开控制球群压缩和膨胀；两只张开的手形成传送门，两掌之间的能量绳可以弹开球体。
- 数字材质：球体会显示“水球、果冻、玻璃、火焰、磁力、泡泡”标签。玻璃受到高速冲击会碎裂，磁力球相互吸引或排斥，泡泡和火焰下降更慢。
- 融合与分裂：经过手势接触的同材质软球低速相碰会融合；双手同时捏住一颗球并向两侧拉开，松手后可分裂。
- 身体碰撞：姿态模型检测到身体后，会显示淡色骨架碰撞线；球可以落在肩、手臂或身体轮廓上并沿轮廓滚动。
- 情绪生命：球体标签会显示当前情绪。好奇或孤独的球主动靠近，害羞的球会躲开，开心和调皮的球围绕手运动；快速拍击可能使球生气，数秒后恢复平静。
- 指尖绘轨：只伸出食指并在画面中移动可留下发光轨迹，球会被轨迹引导；画出闭合圆形可生成持续约5秒的环形轨道。

## 8. 常见问题

### 摄像头无画面

- 检查浏览器地址栏中的摄像头权限。
- 关闭正在占用摄像头的其他应用。
- 刷新页面后重新点击“启动摄像头”。

### 状态灯一直是红色

- 红色表示识别链路未连接：尚未启动摄像头，或摄像头已关闭。
- 点击“启动摄像头”后应变为绿色；若仍为红色，检查摄像头权限、设备占用与网络（首次需加载模型）。

### 页面组件重叠

- 使用最新版页面样式。
- 推荐浏览器缩放100%—125%。
- 桌面端页面会根据窗口高度自动切换紧凑布局。

### 模型加载失败

- 检查网络连接。
- 重新执行 `npm install`。
- 确认 `node_modules/@mediapipe/hands` 存在。

### 字母识别不稳定

- 保持手掌正对摄像头。
- 避免手指互相遮挡。
- 将左右两只手适当分开。
