# 使用手册

## 1. 环境要求

- Node.js 20或更高版本；当前验证版本为22.14.0。
- npm；当前验证版本为11.11.0。
- Chrome或Edge浏览器。
- 可用摄像头和正常网络连接。

## 2. 安装与启动

打开PowerShell并执行：

```powershell
cd D:\hand_gesture_grab
npm install
npm run dev
```

浏览器访问：

```text
http://localhost:5173/
```

## 3. 启动摄像头

1. 点击“启动摄像头”。
2. 浏览器询问权限时选择“允许”。
3. 等待页面状态显示检测到手部。
4. 保持光线充足，并让完整手掌进入摄像头范围。

页面刷新后浏览器会关闭旧媒体流，需要重新点击一次“启动摄像头”。

## 4. 识别字母

- 单手1—5根手指对应A—E。
- F—Z使用双手组合完成。
- 页面会同时显示左侧手、右侧手、双手总数和字母编码。
- 当前字母会在A—Z列表中高亮，并使用英语播报。

常用示例：

| 目标字母 | 左侧手 | 右侧手 |
| --- | --- | --- |
| A | 0 | 1 |
| F | 1 | 0 |
| L | 2 | 0 |
| R | 3 | 0 |
| X | 4 | 0 |
| Z | 4 | 2 |

## 5. 抓取收藏品

1. 张开拇指和食指，将屏幕光标移动到收藏品上方。
2. 捏合拇指和食指完成抓取。
3. 移动手掌拖动收藏品。
4. 再次张开拇指和食指释放收藏品。

成功抓取后，页面会弹出对应动图并播报真实物品名称。

## 6. 生产构建

```powershell
cd D:\hand_gesture_grab
npm run build
```

构建文件输出到 `dist` 目录。

## 7. 常见问题

### 摄像头无画面

- 检查浏览器地址栏中的摄像头权限。
- 关闭正在占用摄像头的其他应用。
- 刷新页面后重新点击“启动摄像头”。

### 页面组件重叠

- 使用最新版页面样式。
- 推荐浏览器缩放100%—125%。
- 桌面端页面会根据窗口高度自动切换紧凑布局。

### 模型加载失败

- 检查网络连接。
- 重新执行 `npm install`。
- 确认 `node_modules/@mediapipe/hands` 存在。

### 字母识别不稳定

- 保持手掌正对摄像头。
- 避免手指互相遮挡。
- 将左右两只手适当分开。
